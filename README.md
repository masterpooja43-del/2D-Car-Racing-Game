# 🏎️ 2D Car Racing Game

A 2D car racing game developed using **Python and Pygame**. The game features multiple cars, racing lanes, enemy vehicles, coins, obstacles, nitro boost, fuel, health, levels, scoring, and high-score saving.

## 🎮 Features

- 🛣️ 3-lane racing system
- 🚗 Multiple player cars
- 🚘 Multiple enemy cars
- 🚀 Nitro boost
- ❤️ Health system
- ⛽ Fuel system
- 🪙 Coin collection
- 🚧 Road obstacles
- 🏆 Score and high-score system
- 📈 Increasing difficulty
- 🏁 Multiple levels
- ⏸️ Pause and resume
- 🔄 Restart functionality
- 🎨 Animated road and scenery
- 💾 High-score saving

## 🛠️ Technologies Used

- Python
- Pygame

## 🎮 Controls

| Key | Action |
|---|---|
| Enter | Start Game |
| C | Select Car |
| Left Arrow | Move Left |
| Right Arrow | Move Right |
| Space | Nitro Boost |
| P | Pause / Resume |
| R | Restart |
| Esc | Exit |
